# QLANE.md

## Critical flows

### P0

- Create a project and see it in the project list.
- Add a task to a project, mark it done, and see it move to the done filter.
- Rename a project and see the new name in the sidebar.

### P1

- Add a label to a task and filter the task list by it.
- Move a task between buckets on a Kanban view.

## Accounts and roles

- `qa-admin` owns the seeded projects; `qa-user` is a regular member.
- Create new accounts at /register?offer=pr-edit, never from the plain registration page.

## Areas to skip

- Instance administration: it needs a licence this deployment does not have.
